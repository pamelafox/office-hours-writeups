🐍 This week's Python + AI Office Hours mixed practical career questions with live experiments in agent tooling.

Topics we covered:

🧠 Python and DSA for AI: Even with coding agents, developers need enough Python to read generated code, spot questionable patterns, and improve efficiency with the right data structures and algorithms.

🧩 Agent Plugins: We explored the portable format for bundling skills and MCP servers, then tested a new plugin across VS Code, Copilot CLI, and ChatGPT with mixed results.

🔍 Chat debugging: VS Code's Chat Debug View exposes model requests, system instructions, skills, subagents, tools, and deferred tool-loading behavior.

🤝 Multi-model review: Copilot does not automatically send every request to several models, but you can explicitly ask it to run model-specific subagents in parallel.

📝 Agent-maintained documentation: Skills can keep Markdown project records consistent, but teams still need to decide whether those files optimize for human readability or later LLM analysis.

News:

🔀 Stacked pull requests: GitHub's public preview helps teams keep dependent changes small and reviewable.

🖥️ Muse Glimmer: Meta released a new open-weight model for local experimentation, though its size makes hardware requirements worth checking first.

🔒 Sandboxing lessons: The Hugging Face incident reinforced the need to verify that an AI sandbox is genuinely isolated.
