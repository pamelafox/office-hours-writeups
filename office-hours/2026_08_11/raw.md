## Weekly News Roundup - August 11, 2026

**7-day scan:** August 5-11, 2026

## 🏢 Microsoft / GitHub

Foundry migrations, Copilot releases, developer tooling, security, and usage controls.

### [GitHub launches stacked pull requests](https://github.blog/changelog/2026-07-30-stacked-pull-requests-are-now-in-public-preview/)

The public preview makes large changes easier to review as ordered, focused PRs that can be reviewed and merged independently or together.

### [Azure OpenAI resources move to Foundry](https://learn.microsoft.com/en-us/azure/foundry/how-to/upgrade-azure-openai-auto)

Eligible resources are being auto-upgraded while retaining names, endpoints, keys, identity, and settings.

### [Copilot's weekly release spans app, CLI, and VS Code](https://github.blog/changelog/2026-08-07-github-copilot-weekly-releases-august-3)

Updates add parallel sessions, isolated worktrees, rewind, browser feedback, multilingual dictation, and side questions.

### [Build slash commands for GitHub Copilot](https://github.blog/ai-and-ml/github-copilot/a-guide-to-slash-commands-in-the-github-copilot-app/)

A practical guide shows how app commands package repeatable, repository-aware workflows.

### [GitHub expands malware advisories beyond npm](https://github.blog/security/supply-chain-security/how-we-took-malware-advisories-beyond-npm/)

The advisory program broadens ecosystem coverage so maintainers can coordinate fixes for malicious packages.

### [Copilot reports tokens by model](https://github.blog/changelog/2026-08-11-per-model-token-breakdown-in-the-usage-report)

Usage reports now expose input, output, cache read, and cache write tokens behind AI credit charges.

### [Copilot web adds conversation controls](https://github.blog/changelog/2026-08-10-copilot-on-web-expands-conversation-controls)

Chat can be minimized and resumed, while token indicators show per-session and per-message spend.

### [Code review effort levels reach GA](https://github.blog/changelog/2026-08-07-copilot-code-review-effort-levels-are-generally-available)

Lite and Balanced modes let teams match Copilot review depth to a pull request's complexity and risk.

## 🌐 Industry

Frontier and open models, portable agent tooling, retrieval experiments, observability, and security.

### [Agent Plugins standardizes skills and MCP bundles](https://agent-plugins.org/)

The vendor-neutral 1.0 format packages reusable agent skills and MCP server configurations for compatible clients.

### [Meta releases Muse Glimmer 30B](https://huggingface.co/meta-models/Muse-Glimmer-30B)

The Apache-licensed multimodal model targets local agentic tasks, tool use, reasoning, and failure recovery.

### [Six PDF retrieval approaches put to the test](https://aieng.community/blog/what-actually-improves-pdf-retrieval)

Tests across 80 queries and 1,200 pages found that page-image embeddings do not automatically beat text retrieval.

### [Logfire MCP brings traces into coding agents](https://pydantic.dev/events/ask-your-traces)

Developers can ask questions about real telemetry without leaving their editor or manually scanning hundreds of spans.

### [Benchmark tests whether agents use skills well](https://arxiv.org/abs/2608.04828)

Skill-Use separates failures to trigger the right skill from failures to follow its procedure across 177 tasks.

### [OpenAI details the Hugging Face incident](https://simonwillison.net/2026/Aug/7/openai-timeline/)

A Black Hat presentation and reconstructed timeline explain how an exposed token led to a major model repository compromise.
